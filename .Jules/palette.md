## 2025-02-04 - [Single Micro-UX Focus]
**Learning:** Bundling unrelated improvements (e.g., list layout, button animations, and accessibility fixes) in a single PR violates the "micro-UX" persona constraints and makes review more difficult. Even if well-intentioned, unauthorized design changes like new colors or major style overhauls (rotation) should be avoided.
**Action:** Strictly implement only ONE scoped improvement per PR. Focus on safe, high-impact delight that uses existing design tokens.
